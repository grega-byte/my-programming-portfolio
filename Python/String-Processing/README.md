# String Processing

## 1. Project Name

String Processing Exercises

## 2. Overview

Exercises that inspect and transform strings, count patterns, and check suffix or character conditions.

## 3. Features

- Counts vowels in entered text.
- Compares the counts of the words `cat` and `dog` after lowercasing.
- Removes non-letter characters in helper functions and searches text for character patterns.
- Checks suffixes without regard to letter case and tests a restriction on a preceding period.

## 4. Technologies Used

- Python

## 5. Key Concepts Demonstrated

- String iteration and indexing
- Case conversion and character filtering
- Substrings and suffix checks
- Search and count operations
- Boolean return values

## 6. How to Run

Run an exercise individually, for example:

```text
python p18p2.py
```

Interactive scripts request text in the terminal. No external packages are required by these exercises.

## 7. Project Structure

- `p10p3.py`: counts lowercase vowels in repeated word input.
- `p17p3.py`–`p17p5.py` and `p18p1.py`: text comparisons and character filtering.
- `p18p2.py`–`p18p3.py`: pattern-counting examples for `code`-like strings.
- `p18.p4.py` and `p18p5.py`: suffix and preceding-character checks.

## 8. What I Learned

These exercises practise reading strings character by character and combining built-in string operations with explicit conditions.

# Functions and Recursion

## 1. Project Name

Functions and Recursion Exercises

## 2. Overview

Exercises exploring function definitions, return values, scope, factorial and Fibonacci calculations, and recursive definitions.

## 3. Features

- Defines functions for factorials, Fibonacci values, square-root approximation, and maximum selection.
- Demonstrates local and global names and functions that print versus return values.
- Includes recursive examples with base cases and recursive calls.
- Includes accompanying written notes about function output and recursion limits.

## 4. Technologies Used

- Python

## 5. Key Concepts Demonstrated

- Function parameters and return values
- Scope and variable names
- Base cases and recursive calls
- Iteration versus recursion

## 6. How to Run

Run an exercise individually, for example:

```text
python p12p1.py
```

Most scripts request input in the terminal. The notes are text files and are not executable programs.

## 7. Project Structure

- `p11p1.py`–`p11p4.py` and `p12p1.py`–`p12p3.py`: factorial, Fibonacci, Catalan-number, and square-root exercises.
- `p13p1.py`–`p13p6.py`: function behavior, scope, maximum selection, and factorial function examples.
- `p14p5.py`–`p14p6.py`, `p15p1.py`–`p15p6.py`, `p16p1.py`–`p16p2.py`, and `p20p2.py`: recursive function exercises, including Fibonacci.
- `p13q3.txt`, `p14q1.txt`, and `p14q2.txt`: written observations about function calls, large results, and recursion limits.

## 8. What I Learned

These exercises show how functions can package reusable calculations, how returned values differ from printed output, and how recursive calls depend on base cases.

## 9. Future Improvements

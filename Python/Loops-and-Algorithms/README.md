# Loops and Algorithms

## 1. Project Name

Loops and Algorithms Exercises

## 2. Overview

A set of exercises using repetition to build sequences, tables, totals, and simple number checks.

## 3. Features

- Produces running totals and multiplication tables.
- Calculates factorials and a combinations-style count.
- Checks divisibility and searches for perfect squares or cubes.
- Sums values divisible by 3 or 5 in a generated sequence.

## 4. Technologies Used

- Python

## 5. Key Concepts Demonstrated

- `for` and `while` loops
- Loop counters and accumulators
- Nested loops
- Integer arithmetic and divisibility checks
- Input-controlled repetition

## 6. How to Run

Run an exercise individually, for example:

```text
python p9p3.py
```

Programs that prompt repeatedly continue until their documented sentinel value is entered. Other exercises run with a single input or fixed limits.

## 7. Project Structure

- `p7p3.py`–`p7p5.py`, `p8p1.py`, `p8.p2.py`, `p8p3.py`–`p8p4.py`: loop practice, divisibility, tables, and ranges.
- `p9p1.py`–`p9p5.py`: totals, factorials, and a combinations-style calculation.
- `p10p1.py`–`p10p2.py`: perfect-square and perfect-cube searches.

## 8. What I Learned

The exercises practise controlling repeated work with loop conditions, counters, accumulators, and nested iteration.

## 9. Future Improvements

- Add input checks for values that are expected to be non-negative.
- Compare the search-based root checks with more direct algorithms.

# Python Fundamentals

## 1. Project Name

Python Fundamentals

## 2. Overview

A collection of short introductory exercises covering printed output, variables, arithmetic, strings, indexing, and slicing.

## 3. Features

- Prints fixed text and calculated values.
- Demonstrates string concatenation, indexing, and slicing.
- Includes written examples of string index and slice behavior.

## 4. Technologies Used

- Python

## 5. Key Concepts Demonstrated

- `print()` and basic output
- Variables and arithmetic expressions
- String concatenation, indexing, and slicing

## 6. How to Run

Run an individual exercise with Python, for example:

```text
python p1p1.py
```

Some exercises print fixed output; the string exercises show indexing and slicing examples.

## 7. Project Structure

- `p1p1.py`–`p1p3.py`, `p2p1.py`–`p2p5.py`, and `p3p1.py`–`p3p3.py`: introductory output, string, and arithmetic exercises.
- `p2p4.txt` and `p2p5.txt`: accompanying examples and notes about indexing and slicing.

## 8. What I Learned

These exercises practise how Python represents values, evaluates arithmetic, and accesses parts of strings.

# Number Theory

## 1. Project Name

Number Theory Exercises

## 2. Overview

Small programs that explore prime numbers, factors, common divisors, and sums of proper divisors.

## 3. Features

- Tests numbers in a fixed range for primality.
- Finds common divisors for entered values and divisor tuples for a value.
- Examines sums of proper divisors across a range of numbers.

## 4. Technologies Used

- Python

## 5. Key Concepts Demonstrated

- Divisibility and modulo
- Loops and conditional branches
- Functions and tuple results
- Basic number-theory definitions

## 6. How to Run

Run an exercise individually, for example:

```text
python p14p3.py
```

Some scripts use a fixed range; others request integer input in the terminal.

## 7. Project Structure

- `p14p3.py`–`p14p4.py`: prime-number checks over a small fixed range.
- `p16p3.py`, `p16p4.py`, `p17p1.py`, and `p17p2.py`: common divisors, divisor tuples, and proper-divisor sums.

## 8. What I Learned

The exercises practise how repeated divisibility checks can be used to explore factors and classify integers.

## 9. Future Improvements

- Allow a user-selected range and handle zero and negative inputs explicitly.
- Avoid repeated divisor checks where a more efficient search is suitable.

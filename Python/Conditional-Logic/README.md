# Conditional Logic

## 1. Project Name

Conditional Logic Exercises

## 2. Overview

Short interactive exercises that use conditions to classify values, compare numbers, check a year, and choose a message.

## 3. Features

- Checks signs and ranges for numeric input.
- Looks up a city in fixed tuples and reports its listed province.
- Selects the largest odd value from three entered integers.
- Checks leap years using divisibility rules.
- Includes password comparison exercises with values embedded in the source code.

## 4. Technologies Used

- Python

## 5. Key Concepts Demonstrated

- `if`, `elif`, and `else`
- Comparisons, Boolean operators, and modulo
- Membership checks with tuples
- Nested conditional statements

## 6. How to Run

Run an exercise individually, for example:

```text
python p7p2.py
```

Interactive programs request input in the terminal. The password exercises use fixed values in their source; they are demonstrations, not secure authentication programs.

## 7. Project Structure

- `p5p1.py`–`p5p5.py` and `p6p1.py`–`p6p5.py`: number, name, city, and password condition exercises.
- `p7p1.py`–`p7p2.py`: leap-year checks.

## 8. What I Learned

These exercises practise expressing decision rules with comparisons, Boolean logic, nested branches, and membership tests.

## 9. Future Improvements
